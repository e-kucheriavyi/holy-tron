# Чего? Кого?

Ты тут, потому что сидишь сейчас на воркшопе HolyJS.

## Что делать:

1. Склонируй репозиторий.
2. Открой директорию `client`.
3. Запусти команду `pnpm install` (или `npm install` или `yarn` — я не осуждаю).
4. Запусти команду `pnpm dev`.
5. Развлекайся.

## Игровой клиент

```sh
cd client
npm install
npm run dev
```

Открой адрес из терминала (обычно `http://localhost:5173`). По кнопке «Войти на арену» запускается самостоятельная тренировка против трёх ботов — сервер не требуется. Стрелки или WASD меняют направление, на телефоне доступны кнопки под полем. Цикл движется автоматически; столкновение со стеной или следом завершает его путь. После финала можно начать следующий раунд.

В панели пилота можно изменить позывной, переключиться в «Онлайн» и указать WebSocket-сервер. По умолчанию используется адрес из исходного клиента: `wss://tron.larana.tech/ws`. Ник и адрес сохраняются в браузере. Если вход закрыт во время раунда, клиент повторяет попытку до 45 секунд; подключение можно отменить.

Для своего сервера открой отдельный терминал:

```sh
cd server
npm install
npm run serve
```

В клиенте выбери «Онлайн» и укажи `ws://localhost:2026`. Для запуска матча подключи минимум двух пилотов, например в двух вкладках. На HTTPS-странице нужен адрес `wss://`. Сервер управляет началом и перезапуском онлайн-раундов.

Проверки и сборка клиента (Node.js 22.18+):

```sh
cd client
npm test
npm run build
npm run preview
```

Статическая сборка находится в `client/dist`. Для тренировки достаточно раздать эту папку обычным веб-сервером. Шрифты загружаются из Google Fonts; без доступа используются системные шрифты.

Клиент открывается в 3D с камерой за 3D-лягушкой, низкими световыми следами вдоль пола, отражениями и ярким стадионом вокруг арены: зрители с анимацией рук, огромные цветные фигуры, неоновые кольца и блоки. В 3D `A / D` или `← / →` поворачивают относительно текущего движения; `C` переключает камеры «Погоня», «Глаза», «Обзор», `F` — полный экран. В обзоре камера вращается мышью. В 2D стрелки и WASD задают направление на карте. Переключатель `2D / 3D` сохраняет текущий матч. Если WebGL недоступен, клиент использует 2D. Гараж и справка приостанавливают локальную тренировку; онлайн-матч продолжает идти на сервере.

Карьерная статистика сохраняется для позывного в браузере, отдельно для тренировки и онлайна: заезды, победы, доля побед, пробег, повороты, рекорд выживания, серии и восемь последних результатов. Время выживания фиксируется при гибели; выход из начавшегося заезда записывается как сход.

В «Гараже» доступны девять косметических скинов. Кейсы открываются бесплатно (0 монет). Вероятности редкостей: 70% серийный, 25% редкий, 5% легендарный; внутри редкости предметы равновероятны. Дубликат приносит 60 монет. Предмет сохраняется до анимации открытия, выбранный скин меняет окрас 3D-лягушки. Инвентарь и валюта общие для обоих режимов одного позывного и хранятся только в этом браузере. Цвет следа в онлайне по-прежнему задаёт сервер.

Мотоциклы заменены объёмными лягушками с глазами, лапами, пятнами и лёгкой анимацией прыжка. При уменьшенном движении анимация отключается; управление, коллизии и низкий световой след работают по прежним правилам. Все открытые скины и инвентарь сохраняются.
