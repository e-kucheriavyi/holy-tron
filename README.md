# Чего? Кого?

Ты тут, потому что сидишь сейчас на воркшопе HolyJS.

## Что делать:

1. Склонируй репозиторий.
2. Открой директорию `client`.
3. Запусти команду `pnpm install` (или `npm install` или `yarn` — я не осуждаю).
4. Запусти команду `pnpm dev`.
5. Развлекайся.

## Игровой клиент

```sh
cd client
npm install
npm run dev
```

Открой адрес из терминала (обычно `http://localhost:5173`). По кнопке «Войти на арену» запускается самостоятельная тренировка против трёх ботов — сервер не требуется. Стрелки или WASD меняют направление, на телефоне доступны кнопки под полем. Цикл движется автоматически; столкновение со стеной или следом завершает его путь. После финала можно начать следующий раунд.

В панели пилота можно изменить позывной, переключиться в «Онлайн» и указать WebSocket-сервер. По умолчанию используется адрес из исходного клиента: `wss://tron.larana.tech/ws`. Ник и адрес сохраняются в браузере. Если вход закрыт во время раунда, клиент повторяет попытку до 45 секунд; подключение можно отменить.

Для своего сервера открой отдельный терминал:

```sh
cd server
npm install
npm run serve
```

В клиенте выбери «Онлайн» и укажи `ws://localhost:2026`. Для запуска матча подключи минимум двух пилотов, например в двух вкладках. На HTTPS-странице нужен адрес `wss://`. Сервер управляет началом и перезапуском онлайн-раундов.

Проверки и сборка клиента (Node.js 22.18+):

```sh
cd client
npm test
npm run build
npm run preview
```

Статическая сборка находится в `client/dist`. Для тренировки достаточно раздать эту папку обычным веб-сервером. Шрифты загружаются из Google Fonts; без доступа используются системные шрифты.

Клиент открывается в 3D: перспектива, объёмные световые циклы и следы с неоновым свечением. Потяни по арене мышью или пальцем, чтобы повернуть камеру. Переключатель `2D / 3D` под ареной меняет вид во время матча. Если WebGL недоступен или графический контекст потерян, клиент использует 2D. Трёхмерный рендерер загружается отдельным модулем и останавливается при переходе в 2D.
